# Build Flutter Apps Plugin

This Codex plugin packages modern Flutter and Dart development workflows for
multi-platform app setup, widgets, adaptive layouts, architecture, testing,
native integrations, debugging, DevTools profiling, and memory investigation.

## Included Skills

- `flutter-project-setup`
- `flutter-debugger-agent`
- `flutter-platform-integrations`
- `flutter-adaptive-ui`
- `flutter-ui-patterns`
- `flutter-view-refactor`
- `flutter-performance-audit`
- `flutter-devtools-performance`
- `flutter-memory-leaks`
- `flutter-testing`

## Requirements

Install the Flutter SDK and the platform toolchains required by the selected
targets. Run `flutter doctor -v` before device workflows.

The plugin intentionally uses Flutter CLI, Dart VM Service, DevTools, and native
platform tools instead of requiring a third-party MCP server.
