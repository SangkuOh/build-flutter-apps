# Flutter Components Index

| Component family | Review focus |
| --- | --- |
| Long lists and grids | Lazy builders, item identity, image cost, pagination |
| Forms | Controller lifecycle, validation, keyboard, focus traversal |
| Async content | Stable future or stream ownership, loading, empty, error, retry |
| Navigation | Central route ownership, deep links, back behavior |
| Dialogs and sheets | One presentation model, dismissal, platform fit |
| Images | Decode dimensions, caching, placeholders, semantics |
| Adaptive shells | Constraints, safe areas, navigation shell changes, restoration |
| Animations | Rebuild scope, repaint boundaries, controller lifecycle |

Official entry points:

- Widget catalog: `https://docs.flutter.dev/ui/widgets`
- Cookbook: `https://docs.flutter.dev/cookbook`
- Accessibility: `https://docs.flutter.dev/ui/accessibility-and-internationalization/accessibility`
